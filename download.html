OMNI

Windows app

Omni is a chat and meeting app. The Windows copy is one program named Omni. This page only offers a file when a real https address, version, and checksum are configured. Nothing is published here yet.

Download

Checking the download settings…

What you get

The file, when it exists, is an unpacked zip. Extract it and run Omni.exe. That is not a setup wizard. There is no installer and no automatic update in the current build.

After you extract it

  • Keep one folder and point the shortcut at Omni.exe.
  • Sign-in is remembered in %APPDATA%\Omni.
  • Online chat needs the internet. There is no guest entry in the desktop app.
